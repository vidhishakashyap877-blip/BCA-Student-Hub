
# BCA Student Hub 🎓

## About the Project
BCA Student Hub is a student-focused educational website
developed to organize useful academic information and
learning resources for BCA students.

## Features
- Home page with website introduction
- About section
- BCA subject information
- Study resources with external links
- My Learning Journey section
- Contact form
- Responsive layout

## Technologies Used
- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Media Queries

## Project Structure

BCA-Student-Hub/
│
├── index.html
├── style.css
└── README.md

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
